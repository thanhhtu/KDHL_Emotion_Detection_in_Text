This branch contains all essential components for a comprehensive data analysis workflow, including:

📄 Raw Data Files (.csv, .json):
Collected datasets used for analysis, stored in both CSV and JSON formats. These files serve as the foundation for data processing and modeling.

🧹 Data Cleaning Scripts:
Python scripts to preprocess and clean the raw data — handling missing values, formatting issues, duplicates, and ensuring data consistency for accurate analysis.

🕷️ YouTube Comment Crawler:
Custom scripts to crawl YouTube video comments via the YouTube Data API v3.
